# MCSM (Minecraft Server Manager)

## 🇯🇵 概要 / Overview
このツールは、Minecraft Java版のサーバーを簡単に構築・管理できる自作ツールです。
全バージョンに対応しており、必要なサーバーJARファイルの自動取得も可能です。

This tool is a utility to easily build and manage Minecraft Java Edition servers.
It supports all versions and automatically downloads the required server JAR files.

---

## 🛠️ 使い方 / How to Use

### 🇯🇵 日本語
1. 本ツールを適当なフォルダに解凍して起動します。
2. 「参照...」ボタンから、サーバーを保存するフォルダを選択します。
3. **【重要】**「バージョン一覧取得」ボタンを押すと、ドロップダウンにバージョンが表示されます。
4. ドロップダウンから起動したいバージョンを選びます。
5. 「このバージョンをダウンロード」を押すと、自動でJARファイルが配置されます。
6. 「EULA(利用規約)に同意する」にチェックを入れます。
7. 「サーバー起動」ボタンを押すとサーバーが立ち上がります。

### 🇺🇸 English
1. Extract and launch this tool.
2. Click the "参照..." (Browse) button to select your server folder.
3. **[IMPORTANT]** Click the "バージョン一覧取得" (Get Version List) button to load versions into the dropdown.
4. Select your desired version from the dropdown.
5. Click "このバージョンをダウンロード" (Download this version) to automatically fetch the JAR.
6. Check the "EULA(利用規約)に同意する" (Agree to EULA) box.
7. Click "サーバー起動" (Start Server) to launch your server.

## 📋 UIの対訳表 / UI Translation Guide
ソフトが日本語表記のため、以下の対訳を参考にしてください。
Since the UI is in Japanese, please refer to the translation below:

- **サーバーフォルダ (Server Folder)** = The directory where server files are saved.
- **参照... (Browse...)** = Select folder.
- **バージョン一覧取得 (Get Version List)** = Fetches and displays available versions.
- **既存のserver.jarを使う場合 (Use existing server.jar)** = To use your own jar.
- **起動設定 (Launch Settings)**
  - 最小メモリ / 最大メモリ (Min Memory / Max Memory)
  - オンラインモードを有効にする (Enable Online Mode / Premium account verification)
- **ポート (Port)** = Server port (Default: 25565)
- **サーバー起動 (Start Server)** / **サーバー停止 (Stop Server)**
- **状態：起動中 (Status: Running)**

---

## ⚠️ 注意事項 / Important Notice
- ※本ツールを使用しても、お使いのルーターでのポート開放（デフォルト：25565）は各自で設定が必要です。
- ※Windowsの警告画面が出た場合は、「詳細情報」→「実行」を押してください。
- * Note: You still need to configure Port Forwarding (Default: 25565) on your router manually.
- * If Windows SmartScreen blocks the app, click "More info" -> "Run anyway".
